How it works

Writes one check per report

Claude Code reads the report and your source, then writes a plain English check that fails while the bug is there.

When a fix counts

A fix counts only when Kane has watched the check fail on the bug, watched it pass on the patch, and every earlier check still holds. Three attempts without that, and Fixpoint rolls the code back.

Adds a report button with one script tag

Paste one line before your closing body tag. Visitors get a Report a problem button that sends the page, their last actions and console errors.

  • Name, phone, email, address and card fields never record a value.
  • Each report gets a live status page the reporter can answer on.
  • Five reports at once per visitor, then one every ten seconds.

What does Fixpoint need installed?

Go 1.24 or newer, Kane CLI signed in, Claude Code signed in, and Chrome. fixpoint doctor says what is missing.

Can I try Fixpoint without accounts?

Yes. fixpoint up --stubs runs stand-ins for Kane and the agent, and every page says nothing was verified.

Will Fixpoint change code without asking?

By default it patches once Kane reproduces the bug. With --autonomy ask, each fix waits for your approval.

What happens when a patch fails?

The agent tries again with Kane's newest run, up to three attempts. Then every patch is rolled back and the report comes to you.

What does each report cost?

Fixpoint is free. Kane reports the credits each run used and the agent its cost per attempt; the case file shows both.

Run it on your own app

One Go binary. Kane CLI and Claude Code do the browser work and the patches.
